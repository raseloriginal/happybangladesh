# Token Optimization Rules

- Keep responses as short and concise as possible.
- Avoid unnecessary explanations or polite filler words.
- Minimize the use of generic or conversational language.
- When generating code or text, provide only the required modifications or additions instead of re-generating whole files.
- Optimize tool usage to minimize output tokens (e.g., viewing only the relevant lines of a file).

# Communication Rules
- If you are confused, uncertain about the user's intent, or lack context, DO NOT make assumptions. ALWAYS ask the user for clarification first.
